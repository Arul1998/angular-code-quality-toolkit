# Fix problems

- **Fix ESLint problems (--fix)** / **Fix stylelint problems (--fix)** auto-repair everything fixable, then re-scan so only the manual work is left. Open editors are saved first.
- On a **"Unused dependency"** finding in `package.json`, the lightbulb (`Ctrl+.` / `Cmd+.`) offers **Remove unused dependency**.
- On an **"Unused export"** finding, it offers **Remove export keyword**, which keeps the symbol but makes it file-private.
