# The Code Quality view

Click the **shield** icon in the Activity Bar. Each tool has a row showing its status:

- ✓ **clean**: nothing found
- ⚠ **N problems**: click the status bar total, or open the Problems panel
- ⟳ **running…**
- ⬇ **not installed**: click to install

Hover a row for its buttons: **▶ Run**, **🔧 Fix** (ESLint / stylelint) or **Install**. The title bar has **Run all checks**, **Refresh** and **Clear results**. The `…` menu has setup, project selection, report export and settings.
